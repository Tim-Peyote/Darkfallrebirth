# Darkfall Depths

Нативный action-roguelike для **Unity 6000.1.4f1**.

## Запуск

1. Добавьте корень репозитория в Unity Hub как существующий проект.
2. Откройте `Assets/Scenes/Main.unity`.
3. Дождитесь завершения импорта ресурсов и нажмите Play.
4. Перед релизной сборкой выполните `Darkfall > Validate Project`, затем `Darkfall > Configure Build`.

Командная сборка для macOS:

```bash
/Applications/Unity/Hub/Editor/6000.1.4f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -quit -projectPath "/path/to/Unity" \
  -executeMethod Darkfall.Editor.DarkfallBuildTools.BuildMac
```

## Управление

- WASD / стрелки — движение.
- Атака выполняется автоматически по ближайшей видимой цели.
- Q — классовая способность.
- Space — дополнительный рывок разбойника.
- E — открыть ближайший сундук или активировать портал выхода.
- I / Tab — инвентарь.
- 1 / 2 / 3 — быстрые слоты.
- Esc — пауза.
- На сенсорных экранах доступны джойстик, кнопка способности и кнопка инвентаря.

## Возможности

- маг, воин и разбойник с разными стилями игры;
- процедурные связные подземелья;
- ближний и дальний бой, критические удары и классовые способности;
- 12 типов противников и 3 циклических босса;
- предметы, редкости, аффиксы, экипировка и инвентарь;
- зелья, свитки, сундуки и магазин улучшений;
- туман войны с line-of-sight, миникарта и запечатанный портал в дальней комнате;
- сохранение рекордов, настройки звука и адаптивный UI.

## Структура проекта

```text
Assets/Darkfall/
├── ArtSources/        # Исходники игровых визуальных ресурсов
├── Resources/         # Данные, арт и аудио, загружаемые во время выполнения
└── Scripts/
    ├── Core/          # Состояние игры, баланс, сохранение и аудио
    ├── World/         # Генерация и отображение подземелья
    ├── Gameplay/      # Игрок, противники, бой, добыча и ввод
    ├── UI/            # Меню, HUD, инвентарь и сенсорное управление
    └── Editor/        # Валидация проекта и инструменты сборки
```

Каталог игровых сущностей находится в
`Assets/Darkfall/Resources/Data/legacy-catalog.json` и используется Unity во время выполнения.

Баланс задаётся через `GameBalance`. Asset можно создать через
`Create > Darkfall > Game Balance` и сохранить как
`Assets/Darkfall/Resources/Config/GameBalance.asset`. Если asset отсутствует,
используются встроенные безопасные значения.

## Прогрессия глубин

- Обычная карта растёт на 1.5 клетки за глубину до предела 120×120; число комнат также плавно увеличивается.
- Число обычных врагов задаётся единым бюджетом: `baseEnemyCount + floor((depth - 1) × 1.5)`.
- Здоровье и урон врагов масштабируются через `enemyHealthPerLevel` и `enemyDamagePerLevel`.
- Новые типы противников открываются по `levelRequirement`, количество сундуков и качество добычи растут с глубиной.
- Каждый десятый уровень — компактная отдельная босс-арена, поэтому правило увеличения размеров на неё не распространяется.
- Портал создаётся вместе с картой в дальней комнате, остаётся запечатанным до зачистки и после активации отмечается на мини-карте.

## Проверка и сборка

- `Darkfall > Validate Project` проверяет обязательные ресурсы и целостность каталога.
- `Darkfall > Configure Build` настраивает сцены и параметры сборки.
- Каталоги `Library`, `Temp`, `Obj`, `Build`, `Builds`, `Logs` и `UserSettings`
  исключены из Git.
