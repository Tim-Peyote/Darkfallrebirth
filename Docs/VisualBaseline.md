# Visual baseline

Зафиксировано 11 августа 2026 года до дальнейшей перестройки генератора и визуального языка.

## Интерфейс

Эталонная матрица лежит в `work/visual-audit/ui/` и содержит семь состояний (`main-menu`,
`hero-select`, `hud`, `inventory`, `pause`, `shop`, `developer`) в разрешениях 1600×900,
1920×1080, 1680×1050 и 2560×1080. Машиночитаемый результат проверки —
`work/visual-audit/ui/layout-report.json`.

## Биомы

Для сравнения мира используются фиксированные глубины начала каждой главы:

| Глубина | Биом | Основной кадр |
|---:|---|---|
| 1 | Пепельные катакомбы | `work/visual-audit/depth-01-ashen-catacombs.png` |
| 11 | Обгоревшие хранилища | `work/visual-audit/depth-11-ember-vaults.png` |
| 21 | Затопленная крипта | `work/visual-audit/depth-21-drowned-crypt.png` |
| 31 | Тленные сады | `work/visual-audit/depth-31-charnel-gardens.png` |
| 41 | Обсидиановый санктум | `work/visual-audit/depth-41-obsidian-sanctum.png` |

Для каждого биома рядом сохранены варианты `-elevation`, `-event` и `-hazard`. Они нужны
для сравнения геометрии стен, тематического события и поверхности опасности независимо от
обычного кадра уровня.

## Правило обновления

Baseline не перезаписывается во время локальной правки. После завершения этапа создаётся
новый датированный набор, а этот набор остаётся точкой сравнения исходного состояния.
