# UI visual audit

## Запуск

В Unity выбрать `Darkfall > Visual Audit > Main Menu`. Проверка сама проходит семь состояний:

1. Главное меню.
2. Выбор героя.
3. Игровой HUD.
4. Инвентарь.
5. Пауза.
6. Магазин-убежище.
7. Режим разработчика.

Каждое состояние рендерится в минимальном поддерживаемом 1600×900, а также в 1920×1080, 1680×1050 и 2560×1080. Результаты сохраняются в `work/visual-audit/ui`.

## Что проверяется автоматически

- кнопка полностью находится внутри области экрана;
- зона клика не меньше 40×40 px;
- независимые интерактивные элементы не перекрывают друг друга;
- каждый PNG создаётся напрямую через RenderTexture без масштаба и панелей Game View.

Сводка находится в `work/visual-audit/ui/layout-report.json`. Нулевой `IssueCount` означает отсутствие перечисленных геометрических дефектов, но не заменяет ручную проверку типографики, контраста, hover/focus-состояний и понятности сценария.

## Текущий baseline

На 11 августа 2026 года полный проход создаёт 28 кадров и завершается с `IssueCount: 0`. Все переходы выполняются из чистого Play Mode, а временное изменение Canvas и sorting order применяется только к тестовому RenderTexture и затем восстанавливается.
